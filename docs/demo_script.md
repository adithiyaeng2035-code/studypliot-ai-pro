# Demo Script

1. Start the app and show the dashboard at `http://127.0.0.1:8000`.
2. Add a Biology reading task due later this week and a short Math review task.
3. Show the task list, upcoming deadlines, and due-date-based study plan.
4. Complete the Math task and point out the refreshed completion and study-time
   statistics.
5. Ask StudyPilot what to focus on next and show the local suggestion.
6. Optionally show the REST API documentation at `/docs` or connect the MCP
   server using `python -m app.mcp.server`.
